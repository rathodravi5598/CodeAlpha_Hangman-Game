# 🎮 Hangman Game 


An interactive, category-driven command-line Hangman Game written in Python. Test your vocabulary and deduction skills across multiple domains with zero external package dependencies.

💡 Overview

This Hangman implementation brings the timeless pencil-and-paper word guessing game straight to your terminal. It offers dynamic category selection, live guess verification, input protection (preventing repeated or invalid keystrokes), and structured visual feedback.

✨ Key Features

 🎯 Diverse Categories: 4 categories with multiple word choices.
 🛡️ Robust Input Sanitization:
  -> Automatically converts inputs to lowercase.
  -> Detects and rejects numbers, multiple letters, and special symbols.
  -> Warns about repeated letter guesses without penalty.

  📊 Real-Time Status Dashboard: Displays current blanks (`_ _ _`), letters guessed so far, and remaining chances.
 ⚡ Lightweight & Fast: Runs instantly out of the box with pure standard Python library (`random`).
